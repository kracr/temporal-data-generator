  ?paper <https://anonymous.com/AcademicConferenceEvent#hasAuthor> ?author .
  ?author <https://anonymous.com/Tweet#hasAffiliation> ?organization .

Shared RDFox daemon process memory with all 3 datastores loaded simultaneously: 65.5 MB working set / 68.9 MB private.

Insight: RDFox latency stays flat (~130-145ms) as fact volume grows ~3.7x (304K -> 1.1M facts), consistent
with an in-memory RETE/datalog engine at this data scale. N=2 and N=5 return the exact same 66 bindings,
meaning conferences beyond the first two do not introduce new author/organization affiliation triples that
satisfy this specific two-hop join pattern under the current generator's population reuse.
